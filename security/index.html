Security

Security research on AI agent tooling.

Coding agents Agent runtimes Guardrails & permissions Coordinated disclosure

I'm an independent security researcher working on the security of AI agent tooling: coding agents, agent runtimes, and the guardrail and permission layers that decide what an autonomous agent may do without a human confirming it.

Where the bugs live

Most of what I find is one class of mistake: the gap between what a guardrail’s matcher believes a path or command is and what the OS or shell actually executes. Path normalization, option-attached arguments, alternate data streams, cross-origin requests to default-on local servers.

How I work

Reproduce in a clean, isolated container before claiming anything.
Report privately to maintainers through coordinated disclosure, with a patch and regression tests where I can.
No public write-ups or PRs until the advisory is published.
